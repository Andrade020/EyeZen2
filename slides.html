SetDeviceGammaRamp recebe três tabelas de 256 pontos, uma por canal — 768 valores no total. Cada canal de entrada (0–255) é remapeado para uma saída (0–65535). É a mesma API que o Night Light usa por trás dos panos.

Fig. 05/10 — a parede invisível
o driver recusa em
silêncio total
Drivers modernos de Windows ignoram SetDeviceGammaRamp quando o ganho de qualquer canal cai abaixo de ~0.50. Não lançam erro. Não retornam falha. A chamada retorna sucesso — e a tela simplesmente não muda. Foi assim que descobrimos por que três filtros "não funcionavam".

Fig. 06/10 — motor b

que virou atalho
A Magnification API foi criada para ampliar a tela para usuários com baixa visão. Como efeito colateral, aceita uma matriz 5×5 que mistura canais livremente — sem o limite do driver de gamma. É assim que o fósforo âmbar e o modo astrônomo existem.

Fig. 07/10 — percepção
trocar de filtro não pode
parecer um flash
Toda troca de filtro interpola 1400ms entre a curva antiga e a nova, usando uma curva de aceleração e desaceleração — 1 − (1−t)³ — em vez de uma transição linear e mecânica. É a diferença entre "a tela mudou" e "a tela se acomodou".
